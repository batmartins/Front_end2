Análise de UX/UI

1 – Qual o significado de UX? Cite um exemplo.
R: UX significa User Experience (Experiência do Usuário). O conceito avalia como uma pessoa se sente, se comporta e interage ao usar um produto ou serviço, seja ele digital (como um aplicativo) ou físico. O objetivo principal é tornar essa jornada simples, útil e agradável. Exemplo: 

2 – Encontre um exemplo real de um software que tenha um bom UX. Por que ele é positivo?
R:Um excelente exemplo real de software com uma ótima experiência do usuário (UX) é o aplicativo do Nubank, amplamente reconhecido por transformar a complexidade dos serviços financeiros em algo simples e acessível .


3 – Qual o significado de UI? Cite um exemplo.
R:UI significa User Interface (Interface do Usuário). Trata-se do meio visual e interativo pelo qual uma pessoa se comunica com um aparelho ou sistema digital, abrangendo botões, cores, fontes e menus. Um exemplo clássico de UI (User Interface) é a tela inicial de um aplicativo de celular ou site, composta por botões, menus e campos de texto. 

4 – Encontre um exemplo real de um software que tenha um bom UI. Por que ele é positivo?
R:O painel do Stripe Dashboard é um exemplo real de software com uma interface de usuário (UI) excelente. Ele transforma dados financeiros complexos em uma experiência visual limpa, organizada e fácil de usar. 

5 - Qual a diferença entre UX e UI? Exemplifique a diferença.
R: UX vs. UI: UX cuida da estrutura e de como o produto funciona; UI (User Interface) cuida da parte visual e estética (cores, botões e ícones).
